# Админ-панель и публикация API на Джино

Админка открывается по адресу `/admin`. Для неё нужен отдельный пароль сервера; он не хранится в Git. Изменения меню, фотографии и заявки хранятся в `source/server/data` и `source/server/uploads`.

## Первичная настройка на Джино

В SSH-консоли перейдите в папку проекта на сервере (в вашем случае — `~/domains/e9a2130bd950.hosting.myjino.ru/source`) и выполните:

```bash
cp hosting-app.cjs ../app.js
read -s -p 'Новый пароль админ-панели: ' HS_ADMIN_PASSWORD
printf '\n'
printf '%s' "$HS_ADMIN_PASSWORD" > server/.admin-password
unset HS_ADMIN_PASSWORD
chmod 600 server/.admin-password
mkdir -p server/data server/uploads
npm ci
npm run build
```

Затем скопируйте содержимое `dist` в `../public_html` так же, как это делает текущий `~/update-site.sh`, и перезагрузите веб-сервер в панели Джино. В `app.js` на уровень выше папки `source` попадает небольшой загрузчик Node API; сам код и зависимости остаются в папке проекта.

Добавьте в `~/update-site.sh` одну строку, чтобы загрузчик обновлялся после каждого `git pull`:

```bash
cp ~/domains/e9a2130bd950.hosting.myjino.ru/source/hosting-app.cjs ~/domains/e9a2130bd950.hosting.myjino.ru/app.js
```

Если путь домена изменится, скорректируйте обе части команды. Не используйте очистку Git с флагом `-x`: данные меню, фотографии и файл пароля намеренно игнорируются Git.

Для публичного сайта и панели нужен HTTPS. Джино направляет обычные статические страницы из `public_html`, а Node-приложение обрабатывает API и запросы к загруженным фотографиям.

## Заявки и статистика

Кнопка «Заказать» в меню открывает форму обратного звонка. Отправленные формы видны в панели; там обращение можно отметить как заказ или завершённое. Телефонные звонки не регистрируются сайтом, поэтому в цифры статистики входят только формы.
